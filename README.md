# Compañí · Finanzas

Este es el proyecto listo para publicar tu app.

## Cómo publicarla (sin usar la terminal)

1. Andá a https://github.com y creá una cuenta gratis (si no tenés).
2. Creá un repositorio nuevo (botón verde "New").
3. Dentro del repo, usá "Add file" → "Upload files" y arrastrá **todo el contenido** de esta carpeta (no la carpeta en sí, sino los archivos y subcarpetas de adentro: `src/`, `index.html`, `package.json`, `vite.config.js`, `.gitignore`).
4. Confirmá el commit ("Commit changes").
5. Andá a https://vercel.com, entrá con tu cuenta de GitHub.
6. "Add New Project" → elegí el repositorio que acabás de crear → "Deploy".
7. En un par de minutos te da un link tipo `https://tu-app.vercel.app`.
8. Abrí ese link en el navegador del celular y agregalo a la pantalla de inicio:
   - **Android (Chrome):** ⋮ → "Agregar a pantalla principal"
   - **iPhone (Safari):** ícono de compartir → "Agregar a pantalla de inicio"

Listo, te queda un ícono en el celular que abre la app en pantalla completa.

## Cómo probarla en tu compu antes de publicar (opcional)

Si tenés Node.js instalado:

```
npm install
npm run dev
```

Y abrís la URL que te muestre en la terminal (normalmente http://localhost:5173).
